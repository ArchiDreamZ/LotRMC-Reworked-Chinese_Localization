## 模组简介
重置版(Reworked)，也可以称之为“再加工版”，是传承版的俄罗斯非官方更新的分支。最初是1.7.10传承版的子模组/分支，现已完全移植到了1.12.2版本，目前正在活跃更新1.12.2版本中。

详细模组介绍请看MC百科页面：[魔戒：重置 (LOTR Reworked)](https://www.mcmod.cn/class/22900.html)

重置版虽然为非官方团队，但其在更新内容上遵照传承版作者Mevans留下的[开发计划](https://lotrminecraftmod.fandom.com/wiki/Planned_Features)，绝大部分更新内容都来自于传承版未完成的计划。

在1.7.10版本中经历了1.0、1.1大北方(The Great North)、1.2中洲森林(Forest of Middle-Earth)、1.3努门诺尔之子(Son of Numenore)，四次大更新。<br/>
重置版添加了许多新的机制，并且也变更了许多原机制，更重要的是增大了游戏体量，拓展补充了东方矮人、洛斯索斯人、可汗德、德鲁伊甸人、林中人类、贝奥恩一族、多古尔都人类、黑努门诺尔人、乌姆巴尔、西刚铎封邑等，各种特色新兵种与房屋，以及添加大量的新路径点。
其中很多新增路径点是原著没有提及过的，参考的是[Middle-earth Role-playing](https://tolkiengateway.net/wiki/Middle-earth_Role_Playing) ，也就是MERP的资料，例如更多的刚铎城市及其历史、卡多蓝的旧城废墟的故事、北方游民的聚居地，安格玛的人类遗址等。
对于参考了MERP的新路径点，彼梦通过查阅MERP资料，在不偏离原文的前提下，对路径点资料进行了充分介绍。
>注：MERP资料可以在“新概念社档案”这个wiki上查到：https://notionclubarchives.fandom.com/wiki/Arda_Role_Playing_Wiki

并且彼梦修正了旧版翻译中不适合游戏命名的“东夷”“南蛮”等偏见他称，改为了“鲁德尔”“哈拉德人”等自称或较客观名称。

# 下载汉化
### 什么是全汉化版？
1.7.10的魔戒传承版、重置版无法自带全中文。

由于魔戒模组自身的特殊性，其书籍、NPC姓名、NPC对话、小任务等（lore、names、speech）未做i18n多语言功能，模组文件中只能存放一种语言文件，重置版官方发布的版本为俄文。<br/>
并且魔戒模组不支持通过资源包替换其文本文件，只能直接编辑模组文件。

因此若想要使用官方全汉化版，就只有两个办法：1.在本Github下载授权发布的“官方全汉化版”，2.手动下载汉化文件并添加入俄文版模组。

### 汉化版模组下载
关于重置版的官方全汉化版模组文件，你可以直接在右侧[**Releases**](https://github.com/ArchiDreamZ/LotRMC-Reworked-Chinese_Localization/releases)中下载到，也可以在中文社区群文件下载。

（官方汉化版模组文件为了防止文件传播时与非官方文件混淆，在模组名中添加了“官方全汉化版”后缀，若不喜欢可手动在 mcmod.info 中删除，或自己手动向模组中添加汉化文件。）

### 直接下载汉化文件
由于汉化经常因发现错误而小型修订，因此仓库Releases中的汉化版模组不一定会第一时间发布，若你追求最完善的汉化，可以手动下载代码区的汉化文件并添加入模组。

点击图中按钮下载汉化，或者直接点击[下载按钮](https://github.com/ArchiDreamZ/LotRMC-Reworked-Chinese_Localization/archive/refs/heads/Archi.zip)：
<img width="299" height="230" alt="image" src="https://github.com/user-attachments/assets/fbd6e2a8-ff0d-4f48-986a-dafb3cf7fdb5" />

然后将下载下来的汉化文件手动加入模组中：使用解压软件（例如WinRAR）打开模组.jar文件，将汉化文件覆盖并替换进`assets/lotr`文件目录中。

# 参与汉化
该项目在Paratranz平台进行翻译，请勿直接修改Github仓库，需要加入该项目的Paratranz平台：[魔戒1.7.10重置版汉化项目-Paratranz](https://paratranz.cn/projects/14171)

如果你发现汉化有疏漏，有的对话漏翻，或者有的内容翻译不恰当，可以前往Paratranz云平台加入项目并在线修改翻译。

目前部分对话与小任务仍然为半机翻，具体哪些可以看Paratranz项目的公告。并且部分魔戒书籍还未汉化：[暂未汉化的魔戒小书籍](https://github.com/ArchiDreamZ/LotRMC-ReWorked-Chinese_localization/wiki/%E5%B7%B2%E5%8F%91%E7%8E%B0%E6%9A%82%E6%9C%AA%E6%B1%89%E5%8C%96%E5%86%85%E5%AE%B9%E5%88%97%E8%A1%A8)

## 仓库文件构成：

**lang**文件夹内是语言文件，是Minecraft中的本地化文件，用于将游戏中的文本翻译成不同的语言，除了魔戒自己设计的NPC姓名、对话、小任务系统，与外置的NBT信息之外，其他所有内容都在这里。

**lore**文件夹内是魔戒书籍的NBT，也就是书籍内容。

**neme**文件夹是魔戒NPC的姓名。

**speech**文件夹是魔戒NPC的对话，以及NPC小任务。


## 翻译历史：

锟斤拷汉化组是最早开始汉化此Mod的团队。2020年末，锟斤拷汉化组组长Mores在Discord浏览Mod时发现了Reworked的存在，随后在组内倡议开始翻译Reworked内容。由组长Mores为主译、副组长12121辅助、FC14_Tim负责一部分材质修复。从2021年2月到5月初，完成了第一个Reworked汉化，翻译了1.0的除对话外的所有的lang文件内容。

1.1大北方更新后，小吴RoobiWu在Mores的基础上汉化完了洛斯索斯人物品与生物名，Mores汉化了1.1补充的可汗德的新装备与生物名。

1.2中洲森林更新后，Mores汉化了德鲁伊甸人、林中人类、贝奥恩一族的装备与生物名，以及1.2补充的多古尔都、河谷邦的新物品与生物名。<br/>
除此之外，随着锟斤拷汉化组与Reworked模组团队的关系拉进，12121与FC14_Tim向Reworked团队提供了部分安格玛、刚铎封邑与洛汗的武器盔甲材质和部分建议。

2022年2月11日，彼梦接手汉化工作，当日汉化完1.2.1版本的所有内容。包括可汗德、林中人类、贝奥恩一族的路径点及其简介，以及安格玛新增路径点及其简介的修正润色，洛斯索斯、林中人类、贝奥恩、伊奥希奥德建筑名，以及可汗德、河谷邦、多古尔都新增的建筑名，重置版新增的13种树木与相应建材家具、砖石、装饰品、植物与作物，1.2版本新增头衔，以及重置版全部派系的盾牌与披风名。<br/>
除此之外彼梦翻译了东方矮人与林中人类的NPC对话，然后由第五纪元服务器的ERUHIR翻译+彼梦修订润色了剩余的洛斯索斯人、可汗德、德鲁伊甸人、贝奥恩一族等所有NPC对话。

1.3努门诺尔之子更新后，2022年6月26日，12121汉化了安格玛与乌姆巴尔的黑努门诺尔人的武器盔甲名、生物名、路径点及其简介，刚铎全部封邑的武器盔甲名，刚铎东部封邑的生物名、路径点及其描述，北方游民的路径点及其描述，可汗德新增路径点及其描述。

2022年8月10日到15日，彼梦第二次接手，汉化1.3版本，初步翻译完成了lang语言文件的所有内容，以及安格玛黑努门诺尔人NPC对话。详细包括安格玛与乌姆巴尔的黑努门诺尔人、刚铎封邑等的新增的成就、建筑、装饰品、披风与盾牌等，并补充修正了安格玛、刚铎诸封邑、北方游民、卡多蓝、可汗德大量的路径点资料，最终一直翻译到1.3.1版本。团队成员Fingolfin也汉化了部分1.3新增的刚铎封邑NPC的对话。

2022年10月10日，刚多林服务器接手，由其服主茶凉带领，补充翻译了剩余的由1.3添加的NPC的对话与所有小任务。但其翻译质量很低，并且添加了过多的玩梗要素，后续由彼梦完全重新翻译了他们所翻译过的黑努门诺尔人与刚铎诸子派系的所有小任务。

2023年1月18日，彼梦建立这个Github仓库，并继续维护汉化。处理剩余所有的汉化遗漏，翻译剩余的NPC对话、NPC姓名、建筑名等，重新翻译部分机翻内容，剩余的汉化更新历史可以在Github更详细的查看。

2023年8月24日，在重置版三周年庆典之际，彼梦将汉化提交给重置版团队，成为如今的重置版官方汉化。但是新的中文版本依然建议在Github以及社区群内下载，因为汉化并不会被及时同步到官方版本。

2025年4月7日，彼梦在Number_Sir的技术支持下，为重置版1.7.10版本创建了Paratranz项目，后续汉化工作可以非常方便的在Paratranz云平台上进行了。

2025年11月7日，彼梦在“葬阳Alxv.aic”使用AI的帮助下，帮助重置版修复了俄文lang语言文件中严重的词条重复问题，并完成了重置版1.12.2的初步翻译，并为1.12.2版本创建Paratranz仓库，自此开始发布1.12.2临时汉化版。

2026年3月18日，彼梦在“葬阳Alxv.aic”使用AI的帮助下超大规模校对了重置版1.7.10与1.12.2版本的翻译，基本扫除了所有lang语言文件中的翻译错误。
